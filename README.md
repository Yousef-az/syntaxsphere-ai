# SYNTAXSPHERE-AI

A futuristic business command center with AI capabilities for analyzing cross-platform data.

## Features

- Dark-themed modern dashboard with glossy UI elements
- Integration with business tools (Slack, Zoho, Salesforce, Gmail, Stripe)
- Interactive data visualizations
- AI-powered data analysis
- Cross-platform analytics

## Tech Stack

- SvelteKit
- TypeScript
- Tailwind CSS
- Chart.js
- D3.js

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
